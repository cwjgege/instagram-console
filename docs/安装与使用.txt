安装
打开 DMG，将“Instagram 控制台.app”拖入 Applications（应用程序）。
也可以直接打开随附的 .app。程序已内置 Python、Tcl/Tk、Pillow、Node.js、Appium、XCUITest 驱动及 WDA 源码，不需要自行安装 Python、Node、npm 或 Homebrew。
本版为 Apple Silicon（M 系列）Mac 构建，不支持 Intel Mac。系统版本还需满足所用 Xcode 的要求。
本版内置 Python 3.14.8 与 Tcl/Tk 9.0.4，更新了窗口运行环境，以修复本机实测出现的鼠标点击无响应问题。升级后已由用户真实鼠标确认按钮恢复响应。
本版使用本地 ad-hoc 签名，尚未完成 Developer ID 签名和 Apple 公证。它是内部测试包；通过互联网传到其他 Mac 后可能被系统安全策略拦截。对外正式分发前需要完成 Developer ID 签名和公证。本程序不会关闭或绕过系统安全保护。

首次准备
1. 在 Mac 安装兼容的完整 Xcode，打开并由你完成协议确认及必要组件安装。
2. 在 Xcode → Settings → Accounts 登录开发签名账号。账号无需与手机 Apple ID 相同。
3. 用 USB 连接 iPhone，解锁，在手机上选择“信任此电脑”。
4. 手机：设置 → 隐私与安全性 → 开发者模式，按提示重启并确认开启。
5. 打开应用。首次会自动打开“设备配置与签名”，准备内置运行环境并检测设备；仅列出 USB 连接的 iPhone。
6. 选择正确设备和签名团队。检测不到团队时先在 Xcode 完成开发证书配置，再重新检测；也可手动输入 Team ID。
7. 点击“安装 / 重新签名控制组件”。首次编译、签名和安装可能需要几分钟，请保持手机解锁并联网。
8. 成功后会自动选择此设备。关闭向导，即可使用主窗口。
9. Instagram 需事先安装并由你登录。应用不会代填 Apple 或 Instagram 密码，也不会要求手机更换 Apple ID。

搜索浏览与恢复（1.1.1）
“搜索浏览”页可设置每次查询观看 1～5 条视频、结果之间滚动 1～3 次，以及每条 5～90 秒的观看区间。默认观看两条，之间滚动一次，每条 10～20 秒。
程序仅点击搜索结果中明确标记为视频的可见控件，观看后通过播放页的返回按钮回到结果，再滚动查找下一条。结果浏览阶段不点赞、不收藏、不评论；未知页面会退出该流程并尝试返回 Reels。
恢复上限现按最近 5 分钟累计，而不是整轮累计；短时间频繁异常仍会停止。滑动后同一视频先等待 2 秒复查，连续三次未变化才恢复，避免一次未翻动就消耗恢复额度。
“诊断运行 20 分钟（含搜索，不互动）”使用当前英文关键词，临时关闭全部社交互动，不更改保存的互动开关。可随时按停止或 Esc。

启动与停止（1.1.2）
停止请求发出后，界面显示已等待的秒数；当前手机命令完成、后台线程退出并释放设备后，才恢复开始按钮。
停止过程中可点击“停止后重新开始”，只排队一次，等上一轮完全退出后自动重新启动。排队重启沿用上一轮模式。
旧控制会话必须实际读到手机当前应用信息才会复用，失效则清理后重建。
创建控制连接或执行手机命令时不会强行截断操作。冷启动可能需要几十秒；界面显示进度与等待时间。Cmd+Enter 可开始普通浏览，Esc 可停止。
后台异常会显示错误并恢复按钮，旧任务的延迟事件不会改变新任务状态。

日常使用
连接并解锁手机，打开应用，点击“开始浏览”或“试运行 45 秒（仅浏览）”。
“停止运行”或 Esc 可请求停止；会等待当前手机命令结束。控制连接重建、编译安装期间可能需要额外等待。
新安装默认关闭自动评论，并设为评论预览。需要评论时自行配置 API Key、规则和发送方式。
API Key 只保留在本次应用进程内，不写入配置。AI 视频采样会发送至你所选模型服务商，使用相应 API 计费。
“手势与连接”可配置滑动安全区、距离、用时、断线重连、USB 重新接入等待秒数和已识别广告咨询面板的恢复策略。
连接或重连前会确认是指定手机的 USB 通道，短暂掉线会限时等待（默认 60 秒）。超时后提示重新插线和解锁；不会静默切换到网络或其他手机。
同一时刻控制一台设备；可保存多台设备的独立控制组件、签名与运行记录，使用前在设备向导切换。
请退出旧版控制台，同一手机不要同时运行两个控制程序。
更换设备不会自动开始浏览。

签名提醒与重新安装
主窗口显示当前设备真实的到期时间，取控制组件描述文件与实际签名证书中较早的日期。
默认提前 48 小时提醒，可在设备向导调整为 1～168 小时。
应用打开时每分钟检查；临近到期或已经到期会弹出提醒。应用关闭后不会在后台提醒，也不安装后台定时任务。
到期后不会直接开始浏览。连接、解锁对应手机，在设备向导点击“安装 / 重新签名控制组件”。
重新安装不保证描述文件或证书有效期自动延长。如果 Xcode 仍使用临近到期的证书或描述文件，需在 Xcode 更新后再次安装；应用仍按真实有效期提醒。
免费 Personal Team 的有效期和设备限额由 Apple 决定，应用不绕过这些限制。

数据与隐私
界面诊断日志仅记录按钮事件、控件类型、坐标和任务状态，不记录输入框内容、按键或 API Key。
配置、设备档案、签名有效期和日志保存在当前 Mac 用户的：
~/Library/Application Support/Instagram Console/
首次会将内置运行环境展开到该目录，安装或升级请预留至少 1 GB 空间，Xcode 编译缓存另外占用空间。
应用复制或升级不需要带上旧聊天目录。对外发送 DMG 或 .app 即可，不要发送此数据目录。
安装包不包含个人 API Key、Apple 账号凭据、签名私钥、手机 UDID、已签名控制组件或运行日志。
开发签名通过本机 Xcode 和钥匙串完成。每台新 Mac/新 iPhone 仍需完成各自的系统信任与签名准备。

故障处理
先确认 USB、解锁、信任、开发者模式以及 Xcode 账号状态，再点击“重新检测连接”。
从“设备配置 / 重新签名”进入向导，可打开诊断日志目录。
浏览遇到验证、限制、未知输入内容或无法确认互动结果时仍会停止，不会重发评论。
签名、安装或系统升级后如连接异常，可停止浏览，再重新签名安装。
首次编译若提示缺少设备支持组件，请在 Xcode 完成组件下载后重试。
自动化和随机手势不是防检测保证，也不能保证账号增长或推荐国家。
