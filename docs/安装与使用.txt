安装
打开 DMG，将“Instagram 控制台.app”拖入 Applications（应用程序）。
也可以直接打开随附的 .app。程序已内置 Python、Tcl/Tk、Pillow、Node.js、Appium、XCUITest 驱动及 WDA 源码，不需要自行安装 Python、Node、npm 或 Homebrew。
本版为 Apple Silicon（M 系列）Mac 构建，不支持 Intel Mac。系统版本还需满足所用 Xcode 的要求。
本版内置 Python 3.14.8 与 Tcl/Tk 9.0.4，更新了窗口运行环境，以修复本机实测出现的鼠标点击无响应问题。升级后已由用户真实鼠标确认按钮恢复响应。
本版使用本地 ad-hoc 签名，尚未完成 Developer ID 签名和 Apple 公证。它是内部测试包；通过互联网传到其他 Mac 后可能被系统安全策略拦截。对外正式分发前需要完成 Developer ID 签名和公证。本程序不会关闭或绕过系统安全保护。

首次准备
1. 在 Mac 安装兼容的完整 Xcode，打开并由你完成协议确认及必要组件安装。
2. 在 Xcode → Settings → Accounts 登录开发签名账号。账号无需与手机 Apple ID 相同。
3. 用 USB 连接 iPhone，解锁，在手机上选择“信任此电脑”。
4. 手机：设置 → 隐私与安全性 → 开发者模式，按提示重启并确认开启。
5. 打开应用。首次会自动打开“设备配置与签名”，准备内置运行环境并检测设备；仅列出 USB 连接的 iPhone。
6. 选择正确设备和签名团队。检测不到团队时先在 Xcode 完成开发证书配置，再重新检测；也可手动输入 Team ID。
7. 点击“安装 / 重新签名控制组件”。首次编译、签名和安装可能需要几分钟，请保持手机解锁并联网。
8. 成功后会自动选择此设备。关闭向导，即可使用主窗口。
9. Instagram 需事先安装并由你登录。应用不会代填 Apple 或 Instagram 密码，也不会要求手机更换 Apple ID。

日常使用
连接并解锁手机，打开应用，点击“开始浏览”或“试运行 45 秒（仅浏览）”。
“停止运行”或 Esc 可请求停止；会等待当前手机命令结束。控制连接重建、编译安装期间可能需要额外等待。

API Key 只保留在本次应用进程内，不写入配置。AI 视频采样会发送至你所选模型服务商，使用相应 API 计费。

支持多台 USB 手机同时运行。每台设备在总览独立开始、停止；双击设备配置参数、查看日志和签名。
请退出旧版控制台，同一手机不要同时运行两个控制程序。

连接中断只重连原 USB 手机，按最近五分钟窗口限制次数。控制服务返回空白错误时也显示具体 HTTP 状态。互动结果不确定时停止，不重复操作。

人工接管：工作区与设备配置页均提供“暂停托管”和“继续托管”。先点暂停，等显示“已暂停托管”后再手动操作手机；正在执行的互动会先完成结果确认，无法确认时仍会停止，避免重复发送。继续时重新识别页面并返回 Reels，跳过接管前和恢复时视频的互动。未完成输入、未知浮层或系统验证会保持暂停，处理后再继续。暂停期间不消耗本轮浏览时长；停止按钮仍然有效。

前台识别：短暂返回空的或系统前台标识时，最多进行三次只读复查，并校验页面所属 App。复查不会重发点击、输入或手势。连续未确认 Instagram 前台才进入原有页面恢复流程；互动结果不确定时仍停止，不自动重发。

无线设备发现与配置迁移（1.2.5 测试版）
工作区 → 添加无线设备：自动检查活动 Wi-Fi / 以太网所在局域网，选择发现的 WDA 后点“验证并保存连接方式”。名称、iOS、地址和标识自动填写。需要查看或修改时展开“显示连接详情 / 手动填写”。
发现仅检查正在运行的 WDA，不安装、签名或启动手机组件，不修改 VPN。默认检查 18100、8100 及已保存地址；预览端口仅在确认 MJPEG 服务后填写。每个活动接口最多检查当前 /24（最多 254 个地址），不扫描 VPN 网段；其他网段或自定义端口请导入配置或手动填写。
WDA 不一定提供真实 UDID。未配对的手机使用指纹生成的连接标识，这不是手机硬件 UDID；该档案仅用于“远程已有 WDA”。首次配对和签名管理仍需通过设备向导。
导出：设备“连接方式”中可导出当前手机；“添加无线设备”中可导出全部已验证无线连接。文件仅包含设备名称、标识、指纹及私网服务地址，不包括证书、私钥、账号或浏览设置。
导入：新 Mac 打开“添加无线设备” → “导入连接配置”，选择原 Mac 导出的 JSON。软件逐台验证指纹和当前系统版本，成功后加入工作区；失败设备保留原配置，不影响成功设备。原 IP 失效时会按原指纹尝试局域网重找，找不到会给出网络和组件检查提示。
导入不会迁移签名能力，统一连接已有 WDA；原 Mac 自己重新导入同一手机时保留本地 Wi-Fi 启动管理。不会复制自动点赞、评论或 API 密钥设置。
手机需处于网络可达、WDA 已运行状态。跨地区不会自动广播发现，请使用可达的私网 / Tailscale 地址。手机重启或组件退出后，仍需已配对的维护电脑恢复 WDA；单靠导入文件不能启动组件。
