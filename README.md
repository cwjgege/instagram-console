# Instagram 控制台

面向 Apple Silicon Mac 的 iPhone 多设备控制桌面应用，支持 USB 与已验证的网络 WDA。源码版本 **1.2.5**（多设备版；公开下载版本以 Release 为准）。

## 功能

- 手动启动、停止；停止后等待任务退出与设备锁释放。
- 英文关键词搜索，识别视频结果、观看、返回并滚动。
- 中央安全区域手势、滑动后页面检查、USB 重连和有界页面恢复。
- 设备配置、控制组件安装/重新签名、签名到期提醒。
- 可配置内容分析与英文评论规则；默认关闭自动评论并使用预览。
- 20 分钟无社交互动诊断模式。

自动化不能保证账号增长、推荐国家或规避平台检测。遇到验证、限制或不能确认的操作结果时停止。

## 1.2.1 桌面界面

设备工作区采用原生 macOS 控件，分开显示设备列表、所选设备详情和操作反馈。短状态与颜色一起区分就绪、运行、停止、连接检测、搜索暂停和错误；详细原因在下方完整显示。检测期间可安排开始，停止可取消等待。

所有设置页支持小窗口查看，表单可滚动，底部保留“保存全部设置”；运行期间明确提示停止后才能编辑。日志和分析结果提供滚动条。支持 Command+S 保存、Control+Tab 切换设置页、聚焦表单后 Page Up/Down 滚动。

165 项自动检查通过，另完成 12 项实际 Tk 布局检查（3 个总览尺寸、7 个设置页、小窗口键盘滚动和空设备状态）。两台实机短程浏览及打包应用操作已验证；本轮没有新的20分钟连续测试。自动化工具的鼠标坐标注入存在偏差，人工鼠标点击仍需后续验证。

## 1.2.0 多设备与 iOS 16

启动进入设备总览，每台 USB 手机可独立开始、停止，双击设备打开其配置、运行记录与诊断导出；支持全部开始、全部停止。设备离线、未完成信任或签名无效时会显示原因，其他设备继续运行。

每台设备使用独立 Appium 服务、WDA 端口、会话、配置、互动台账与日志目录。升级时保留原设备配置；新设备复制初始默认配置，之后单独保存。不会清理其他手机的控制会话。

iOS 16 使用单独的 WebDriverAgent 12.2.2 兼容组件和手机上的 XCTest 框架；较新 iOS 保持现代控制组件。首次安装仍需 Xcode、本机签名、USB 信任与开发者模式。不同 Instagram 页面仍可能需要适配。

关闭某台设备的配置窗口会隐藏窗口并继续该设备任务；点击总览关闭或退出应用会停止所有任务，再释放服务。拔线后显示的连接状态可通过“刷新 USB 连接”更新；运行中的断线处理仅作用于对应设备。

157 项自动检查通过；iPhone 11（iOS18.1）与 iPhone 8 Plus（iOS16.7.16）完成约8分钟多阶段实测，覆盖双机浏览、独立停止重启、搜索视频观看、结果滚动与最终打包应用运行。累计翻页25次、观看搜索视频3条；社交写入均为零。本轮未执行新的20分钟双机连续测试。

总览快捷键：Command+Return 全部开始，Esc 全部停止。

## 开发与检查

使用 Python 3.14（含 Tcl/Tk 9）与 Node.js。安装项目依赖：

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
mkdir -p work
python -m unittest discover -s tests
```

构建 Apple Silicon 应用：

```sh
python tools/build_mac.py
```

构建脚本使用 npm 锁文件安装 Node 依赖，生成 `dist/Instagram 控制台.app`。
该脚本是移植后的构建入口，尚未在第二台 Mac 验证；已发布 DMG 使用本机经过验证的构建环境产生。
仓库不包含预编译运行环境、个人设备配置、API Key、Apple 签名凭据或运行日志。
首次源码运行会由 `src/default-config.json` 生成本地 `src/config.json`；直接运行源码时还需配置本地设备控制服务，推荐用户使用 DMG。

## 1.2.2 手机画面预览

选中设备后在右侧显示只读画面，支持暂停、放大和实时切换 2 / 5 / 10 帧每秒。默认 10 帧每秒；实际帧率受手机和 USB 连接限制。只连接当前设备的预览流，丢弃过时帧；预览故障不停止浏览任务。断开或暂停时保留最后画面与更新时间。画面仅存于内存。

降低帧率主要减少 Mac 解码与显示开销，不会降低手机发送的 MJPEG 流量；暂停会关闭预览连接。控制组件须已启动。

## 1.2.3 设置滚动与点赞间隔

设置表单同时支持普通鼠标滚轮和 Tk 9 的精确触控板滚动事件。浏览设置可配置点赞间隔，默认每浏览 3～8 条不同的 Reels 视频安排一次；到达间隔后，遇到内容匹配且未点赞的视频才尝试点赞。已浏览的视频在本轮不重复计数，不在搜索结果页面执行点赞。每日次数上限独立生效，达到上限后继续浏览。旧的 like_probability 字段不再决定点赞频率。

向导分别显示电脑信任配对、实际组件安装情况与控制接口验证结果。未出现“VPN 与设备管理”开发者条目，不能单独判定安装失败。只有成功连接验证后才标记准备完成。

安装失败按本轮日志区分签名、信任、锁屏、UI 自动化超时、设备支持组件及连接问题，给出对应操作；不再被历史错误误导。已安装且签名有效时，可点击“重新验证已安装组件（不重新签名）”，复用本机编译产物验证连接，不主动卸载或重新构建签名。新 Mac 缺少编译产物时仍需安装一次。

连接错误保留 HTTP 状态与错误类型，避免空白停止原因。自动重连按最近五分钟窗口限制；等待期间只识别原 USB 设备，不切换到其他手机。互动结果不确定时停止，不重放点赞或评论。

## 1.2.5 无线连接测试版

保留原有 USB 安装和运行方式，设备工作区新增“添加无线设备”和每台设备的“连接方式”。连接配置独立保存，不覆盖浏览参数。

- **USB**：默认方式，首次配对、签名安装和 iOS 16 兼容组件沿用原流程。
- **本地 Wi-Fi**：检测本机已配对的网络 iPhone。需要本机已有有效签名记录，当前自动启动只接受 iOS 17 及以上；通过 `devicectl` 直接启动已安装组件，再短暂打开手机设置使组件进入后台，不重新安装或签名。解析开发隧道和本次 WDA 启动日志里的地址，优先保留编译产物实际端口，缺少产物时使用标准端口。首次仍需 USB 配置。
- **远程已有 WDA**：可通过局域网自动发现或配置导入填写设备信息；支持手动填写地址作为备用入口，可选 MJPEG 预览地址。只接管已有 WDA，不通过本机跨地区启动 XCTest，不代替远端签名、配对或手机重启恢复；远端签名状态由当地维护。

网络模式验证 WDA 就绪状态并绑定设备指纹，每次连接重新检查；阻止同一指纹绑定到两个设备档案。指纹用于避免误连，不是认证机制，远程用户填写的 UDID 不能仅凭 WDA 接口独立验证。只使用可信局域网或已授权的 Tailscale 私网，勿暴露 WDA 到公网。

网络模式不再等待 USB、不使用 USB 画面转发；网络预览缺失或断开不停止浏览。原有互动结果不确定时停止且不重放的规则保留。Tailscale 提供 IP 可达性，不保证 Bonjour 发现或苹果开发隧道可用。

验证范围：257 项自动检查通过，包括实际本地 HTTP 验证、重定向拒绝、网络模式跳过 USB、隧道地址变化、端口读取、指纹不一致、重复绑定和跨设备隔离。连接窗口在 620×540 和 780×700 检查通过。

**实机验证范围**：此前 XCTest / IDE 路径出现 code 74；新路径直接启动已安装组件。2026-10-21，td’s iPhone（iOS 18.1）在 USB 连接、Mac VPN 保持开启时，通过局域网读取 WDA 状态、设备信息和页面成功；拔线后再次直接启动已安装组件、读取 Instagram、连续三次滑动及两轮各 25 秒浏览均完成，两轮各翻页 2 次；未执行社交互动。该实机使用现有签名组件对照，尚未覆盖所有本机签名组合。无线 20 分钟、多机连续运行、跨地区 Tailscale 和手机重启恢复尚未验收。两台手机的发现与迁移验证见下文。请保留 USB 作为恢复路径。

网络 WDA 状态每 15 秒自动复查，仅探测已保存地址，不启动或安装组件。控制端口检查失败显示具体原因；预览画面更新不作为控制接口就绪或任务运行的依据。

人工接管：在工作区或设备配置页点击“暂停托管”，显示已暂停后再操作手机；点“继续托管”重新识别并返回 Reels。暂停前及恢复时的视频跳过互动，已完成或待确认的互动记录保留，旧动作不会重新发送。未完成输入、浮层或验证提示会保持暂停。暂停不计入浏览时长，保留会话且仍可停止。

### 无线发现与连接迁移（1.2.5 测试版）

“添加无线设备”可自动发现当前局域网已运行的 WDA，或导入原 Mac 导出的 JSON 连接配置。发现后选择设备即可自动填写名称、系统和服务地址。可导出单台或全部已验证无线连接；导入时验证设备指纹，IP 改变会尝试在局域网重新寻找，失败保留原配置。新 Mac 无需原签名证书即可连接已运行服务。

发现范围为活动 LAN 接口的当前 /24 与常用端口 18100、8100，以及已保存地址。不依赖原 Mac 的配对记录；未获取 UDID 时使用明确标注的指纹连接标识。自定义端口、其他网段和跨地区连接可用配置导入。文件不包含证书、私钥、API 密钥或浏览规则。此功能不负责手机重启后的 WDA 启动与签名续期。
